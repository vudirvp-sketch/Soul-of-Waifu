# Soul of Waifu — fork for agent testing

> **Fork of:** [jofizcd/Soul-of-Waifu](https://github.com/jofizcd/Soul-of-Waifu) (v2.4.0)
> **Purpose:** testing, agent workflow experiments, infrastructure improvements.
> **Upstream README:** see [original README](https://github.com/jofizcd/Soul-of-Waifu/blob/main/README.md)

This fork adds agent-oriented infrastructure files (AGENT_NAVIGATION.md, AGENTS.md, STATUS.md, SECURITY.md, worklog.md, CONTRIBUTING.md, docs/ARCHITECTURE.md, .gitignore) without modifying the application code itself. All infrastructure files are written in English for LLM agent consumption.

For the full project description, features, installation instructions, and community links — visit the upstream repository.

**Key differences from upstream:**
- Agent infrastructure files for structured AI-agent workflow.
- .gitignore tailored for Python/Miniconda desktop app (protects private data, large runtime dirs).
- Security policy (SECURITY.md) for API token and user data handling.
- Iterative workflow documentation (worklog.md, STATUS.md with Known Issues tracking).
