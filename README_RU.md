# Soul of Waifu — форк для тестов и агентов

> **Форк:** [jofizcd/Soul-of-Waifu](https://github.com/jofizcd/Soul-of-Waifu) (v2.4.0)
> **Назначение:** тестирование, эксперименты с агентными workflow, улучшение инфраструктуры.
> **Оригинальный README:** [README upstream](https://github.com/jofizcd/Soul-of-Waifu/blob/main/README_RU.md)

Этот форк добавляет агентные инфраструктурные файлы (AGENT_NAVIGATION.md, AGENTS.md, STATUS.md, SECURITY.md, worklog.md, CONTRIBUTING.md, docs/ARCHITECTURE.md, .gitignore) без изменения кода приложения. Все инфраструктурные файлы написаны на английском — для потребления LLM-агентами.

Полное описание проекта, фичи, инструкции по установке и ссылки на сообщество — в оригинальном репозитории.

**Ключевые отличия от upstream:**
- Агентная инфраструктура для структурированного workflow AI-агентов.
- .gitignore для Python/Miniconda десктоп-приложения (защита приватных данных, крупных runtime-директорий).
- Политика безопасности (SECURITY.md) для API-токенов и пользовательских данных.
- Итеративная документация (worklog.md, STATUS.md с Known Issues).

**Лицензия:** GPLv3 (как и upstream)
